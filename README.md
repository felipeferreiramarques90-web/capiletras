# Capiletras

Mesa interativa para criar cartas com letras ou palavras, escolher cores, sortear letras e virar cartas. A mesa é salva no navegador. Esta primeira versão é uma oficina livre, sem regras de pontuação ou partidas multiplayer.

## Executar

Com Node.js 20 ou superior, execute `npm start`. A porta padrão é 3000; use `PORT` para alterá-la. Não há dependências para instalar nem build obrigatório. `npm run check` verifica a sintaxe.

## Publicar

Os arquivos `index.html`, `style.css` e `app.js` podem ser hospedados diretamente em GitHub Pages, Netlify ou Vercel. No GitHub Pages, publique a raiz da branch que contiver esses arquivos em Settings → Pages. A publicação exige que os arquivos estejam enviados ao GitHub e que Pages esteja ativado.
